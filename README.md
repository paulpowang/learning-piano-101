# NoteNest

A gentle, English-language piano-reading game for complete beginners. The prototype includes an eight-level learning path, interactive notation, a touch/mouse/computer-keyboard piano, positive feedback, tokens, achievements, and local progress saving.

Open `dist/index.html` directly, or serve the `dist` folder with any static web server.

## Progress and sign-in

This prototype stores progress in `localStorage`. Production Google Sign-In and cross-device sync require authentication plus a database/backend. The UI includes a clearly labeled grown-up sign-in placeholder but does not collect account information.
